# Knowledge-Agent

이 프로젝트는 개인이 학습한 지식과 노트를 인공지능(AI)을 활용해 분류·요약·연결하여
체계적으로 정리하는 도구입니다.

주요 목적:
- 학습한 내용을 효율적으로 저장하고 빠르게 검색할 수 있도록 지원
- AI 요약과 태깅으로 지식의 재활용성을 높임
- 지식 간 연관성을 발견하고 지속적으로 업데이트할 수 있게 함

간단 사용 흐름:
1. 지식 입력
2. AI 자동 요약 및 태깅
3. 검색·연결·재학습

## 주요 기능
- **책 정보 자동 수집:** 사용자가 입력한 책(사진, 간단 설명, 제목 등)을 기반으로 인터넷에서 주요 정보를 검색해 개인 저장소에 보관합니다.
- **관심 도서 관리:** 관심 있는 책을 따로 추가하고 추적할 수 있습니다.
- **독후감 작성 및 관리:** 읽은 책에 대한 개인적인 독후감을 쉽게 기록하고 저장할 수 있습니다. (추후 AI 요약/피드백 기능 추가 가능)
- **개인 맞춤 추천:** 사용자의 선호와 읽은 이력에 기반해 좋아할만한 책 또는 읽어야 할 책을 추천합니다.
- **확장성:** 초기에는 책 중심으로 시작하지만, 향후 기사·논문 등 다양한 지식 소스로 확장할 예정입니다.

## 비용 절감 및 구성 방침
- **저비용 운영:** 가능한 한 비용을 절감하는 것을 우선 목표로 합니다.
- **자체 서버 활용:** 집에서 남는 휴대폰을 서버로 재사용하여 호스팅 비용을 최소화합니다.
- **무료 AI 활용:** AI 관련 기능은 우선 무료 또는 오픈소스 모델/서비스를 사용합니다(필요 시 유료 전환 검토).
- **Gateway:** 오픈소스인 `openclaw`를 게이트웨이로 사용합니다.
- **인터넷 검색:** 가능하면 무료 웹 검색 API를 사용하여 외부 정보 수집을 진행합니다.
- **저장소:** Notion의 무료 API(또는 무료 플랜)를 우선 활용하여 데이터 저장을 관리합니다.
- **채널:** 사용자 알림 및 인터페이스는 Google Chat을 사용합니다.
